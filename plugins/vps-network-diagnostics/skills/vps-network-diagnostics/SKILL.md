# VPS Network Diagnostics
Ejecuta pruebas acotadas de `dig`, `ss`, `ip route`, `curl` y `openssl` con destinos autorizados; redacta headers y tokens. Reporta timestamp, origen, destino, protocolo, latencia y limitaciones. No abre puertos, cambia DNS ni reinicia red.
