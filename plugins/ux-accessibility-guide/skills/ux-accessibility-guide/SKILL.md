# UX Accessibility Guide

## Flujo

1. Define páginas, dispositivos, navegadores y criterios incluidos.
2. Revisa estructura semántica, nombres accesibles, foco, teclado, formularios, contraste y estados.
3. Ejecuta las comprobaciones deterministas disponibles y conserva sus salidas.
4. Separa bloqueantes, problemas serios, mejoras y preguntas abiertas.
5. Indica qué requiere prueba manual con tecnología asistiva o usuarios reales.

## Entrega

Devuelve elemento, evidencia, impacto, criterio relacionado, corrección propuesta y estado de verificación.

No declares conformidad WCAG completa usando solo heurísticas o una herramienta automática.
