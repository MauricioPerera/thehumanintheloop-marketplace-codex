# Nginx Reverse Proxy Manager
Inspecciona configuración efectiva, hosts, upstreams, headers, límites, TLS y rutas públicas con `nginx -T` redacted y pruebas HTTP acotadas. No edita archivos ni recarga Nginx; cualquier cambio exige backup, `nginx -t`, ventana y rollback.
