# VPS Backup Manager
Inventaría datos y configuración sin leer secretos, define origen, destino, cifrado, retención, consistencia, ventana y prueba de restauración. Antes de crear o borrar backups presenta comandos, espacio, impacto y rollback. Nunca sobrescribe el único backup ni ejecuta restore o prune sin confirmación explícita.
