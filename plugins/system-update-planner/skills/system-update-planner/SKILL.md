# System Update Planner
Consulta versión, paquetes pendientes, kernel, reinicio requerido y servicios afectados sin instalar. Presenta preflight, backup, duración, validaciones posteriores y plan de reversión; nunca ejecuta `apt upgrade`, `dnf update` o reinicios sin confirmación.
