# AI Prompt Workflow

## Flujo

1. Define el resultado observable y quién lo evaluará.
2. Separa contexto disponible, datos faltantes, restricciones y permisos.
3. Especifica formato, ejemplos y condiciones de rechazo.
4. Identifica riesgos de alucinación, privacidad, seguridad y sobrealcance.
5. Propón casos de prueba representativos y casos límite.
6. Evalúa la respuesta contra criterios explícitos; no confundas una respuesta convincente con una respuesta correcta.

## Entrega

Devuelve objetivo, prompt propuesto, supuestos, límites, criterios de evaluación, casos de prueba y riesgos pendientes.

No inventes fuentes ni afirmes que un prompt fue validado si no se ejecutó una evaluación.
