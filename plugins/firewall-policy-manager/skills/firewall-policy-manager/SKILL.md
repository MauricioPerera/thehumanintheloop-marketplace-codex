# Firewall Policy Manager
Inspecciona reglas, listeners y rutas de administración con salida redacted. Compara puertos publicados con políticas efectivas y clasifica exposición. No agrega, elimina ni recarga reglas; cualquier cambio exige plan, sesión de recuperación, rollback y confirmación.
