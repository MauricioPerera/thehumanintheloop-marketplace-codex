# VPS Cost & Capacity Auditor
Correlaciona CPU, RAM, disco, inodos, tráfico, Docker y servicios con timestamps. Distingue mediciones de estimaciones; solicita proveedor y tarifa para costes. No cambia recursos ni recomienda downgrade sin margen, backup y plan de reversión.
