# Database Operations Manager
Identifica motor, endpoint y alcance; inspecciona versión, salud, conexiones, locks, tamaño y mantenimiento sin imprimir credenciales ni datos. Antes de DDL, VACUUM, flush, kill o cambios de configuración presenta impacto, backup, rollback y confirmación explícita.
