# Código de conducta

## Compromiso

Este proyecto busca ser un espacio colaborativo, técnico y respetuoso para crear plugins, skills y Design System Analyses con revisión humana.

Esperamos comunicación clara, crítica sobre el trabajo y respeto por las personas. No se toleran acoso, ataques personales, discriminación, publicación de datos privados, spam ni contribuciones deliberadamente maliciosas.

## Aplicación

Los mantenedores pueden editar, rechazar o retirar contenido que incumpla este código, así como limitar la participación cuando sea necesario para proteger a la comunidad o a los usuarios del marketplace.

Para incidentes, contacta al mantenedor mediante [Mauricio Perera](https://github.com/MauricioPerera). Para vulnerabilidades técnicas, sigue [`SECURITY.md`](SECURITY.md) y utiliza un canal privado.
