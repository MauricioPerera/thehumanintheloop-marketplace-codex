Elige el recurso y tu plataforma. Los plugins comparten sus skills, documentación y validadores; solo cambia el manifiesto de instalación que entiende Claude Code o Codex.

1Elige el plugin o Design System Analysis que quieres usar.

Comandos de instalación
claude plugin marketplace add MauricioPerera/thehumanintheloop-marketplace-codex
claude plugin install linter-seo-geo-2026@thehumanintheloop-marketplace-claude

Estos comandos se ejecutan en la terminal de Claude Code. En Claude Desktop usa + → Plugins → Add plugin. Codex lee .agents/plugins/marketplace.json; Claude Code lee .claude-plugin/marketplace.json.
